One dad joke, written as raw UTF-8 to `entry.txt` in the output directory. No network, no dependencies, no randomness — the same bytes every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

The grader reads `/output/entry.txt`: UTF-8 text, 1 to 200 characters, one joke, no trailing newline.
